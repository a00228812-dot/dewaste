# DeWaste Sonora — prototipo local

Abre `index.html` directamente, o usa Live Server en Visual Studio Code. No requiere instalación ni compilación.

## Recorrido de demo
1. Explora el marketplace: filtros, búsqueda, guardados y publicaciones.
2. Abre un material y envía una oferta. Continúa negociando en Mensajes.
3. Usa el selector superior derecho para cambiar entre Persona, Empresa, Centro de acopio, Administrador de empresa y Administrador de plataforma.
4. Como Centro de acopio registra una entrega; consulta los puntos en Mi tarjeta.
5. Explora canjes, retiro simulado, tarjeta física y simulador de ingresos.
6. Revisa aprobaciones en los dos perfiles administradores.

Los compradores y vendedores acuerdan y realizan la entrega. DeWaste es intermediario.

## Alcance
HTML, CSS y JavaScript, sin backend. Datos solo en memoria; recargar restablece la demo. El QR es decorativo. No se envían mensajes, procesan pagos ni verifican identidades. La tarjeta y saldo muestran un único caso de demostración compartido entre roles. Los nombres reales no implican alianzas; publicaciones y métricas son ficticias. Las comisiones son hipótesis, no tarifas comerciales. La tipografía utiliza Google Fonts con alternativas locales.
